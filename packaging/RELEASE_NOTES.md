肉肉賴桌的新測試版：七隻寵物都換成會真的走路、坐下、打滾的 3D 肉肉，還會在桌面上跳上視窗、追球、曬太陽。解壓縮就能用。

**下載**：Windows 選 `windows-x64.zip`；Linux 選 `linux-x86_64.tar.gz`（一般電腦）或 `linux-aarch64.tar.gz`（ARM）。解壓縮後執行 `chonkGene.exe` 或 `chonkgene`。可以用 `SHA256SUMS` 核對檔案。

**這一版新增**
- 新成員九尾狐「小九」：九條尾巴、紅色紋路，脖子上的鈴鐺會叮噹響
- 七隻都是可以動的 3D 模型：四隻腳的會交替邁步，小雞、小鴨和貓頭鷹會搖搖擺擺地走；尾巴跟著步伐甩
- 會坐、會趴、會睡：睡覺有好幾種姿勢（下巴擱在腳上、捲成一團、側躺、翻肚）
- 桌面變成地形：牠們會跳上視窗頂端，走到邊邊會掉下來，視窗移動時會跟著搭便車
- 摸摸更有反應：按下去會陷進肉裡，摸頭會蹭你的手，搔下巴會抬起頭，肚子按久了會翻肚給你揉；碰到哪裡都會轉過來看你
- 滑鼠移到寵物身上會變成一隻胖胖的小手（按著搓時伸出一根手指，拎起來時握拳）；戳一下會嚇一跳往後跳，再盯著被戳的地方看；按住來回搓就是搔癢：牠會靠過來瞇著眼，狗會踢後腿吐舌頭，貓會踩踩、發出呼嚕聲
- 翻肚大笑時整個身體都躺平在地上，頭也靠著地；說的話不會再被自己的身體擋住
- 拿狗尾草逗牠們：貓會壓低身子撲上去，柴犬和狐狸會撲會拍，小雞小鴨會跳起來啄
- 丟球、丟飛盤給牠們：從選單丟，或直接用滑鼠抓起來甩出去，點一下就踢著滾；柴犬和狐狸會跳起來在半空中咬住飛盤叼回來；球則每一隻都會帶回你面前：柴犬和狐狸用鼻子頂，貓用前掌一路拍，小雞小鴨一下一下啄著推，貓頭鷹等球停下來再飛過去叼回來。叼著東西時被搔癢，搔久了會笑到鬆口
- 玩躲貓貓：在選單選「玩躲貓貓」，牠會躲到螢幕邊邊外面，只露出一點點耳朵，偶爾探頭偷看；點到牠露出來的地方就找到了
- 放一把貓薄荷：大部分的貓會過去蹭臉、翻肚打滾；也有些貓完全不在乎。貓薄荷可以用滑鼠拖到貓旁邊，喜歡的貓過一陣子還會再回來
- 「叫牠…」：坐下、趴下、過來、轉圈、握手。每隻一開始就會，越親近動作越快；心情不好會拖一下，但最後還是會做
- 牠們會陪你：滑鼠停著看東西時會趴下來抓抓癢，打字時會跟著拍拍腳，打太快會歪頭，貓會走到你旁邊窩著，柴犬會跟著節奏打瞌睡（可以在「不打擾」裡關掉；只看鍵盤和滑鼠有沒有在用，不會讀你打的字）
- 每隻偶爾會有自己的小劇場：貓頭鷹飛上樹枝、小鴨在池塘游泳、小雞啄種子、貓曬太陽或追蝴蝶、柴犬啃骨頭、狐狸召喚狐火、甩著尾巴搖鈴；池塘看得出深度，小鴨一下水就開始游，其他寵物路過會踩水
- 兩隻以上會一起玩，而且比以前常玩：柴犬鞠躬邀玩再暴衝、折耳貓拍一下就轉身、曼赤肯翻肚翻不回來、狐狸用尾巴甩人還會搔癢；玩到一半會滾成一團塵雲，只看得到爪子和星星，出來時還喘著氣
- 小九會施展定身術：喊一聲「定！」，其他寵物就被光泡泡高高托到半空中動彈不得，落地後嚇一大跳往後跳、冒冷汗；點泡泡可以提早戳破，點小九可以打斷法術（貓頭鷹會瞪回去，法術反彈到小九自己身上）
- 小九施法時額頭的火焰和眼睛會發光，臉上的紋路變深變長，還會浮現咒印
- 小九的選單多了「施法…」：定身術、狐火、祝福術（大家都冒愛心）、招喚術（大家跑到牠身邊排好）
- 小九施法的狐火更大、竄得更高；旁邊的寵物會依個性反應：膽小的嚇一大跳、縮著發抖，活潑的開心連跳三下冒愛心，貓會壓低身子扭屁股再撲向火焰
- 新的「肉肉舞」：在「叫牠…」選「跳舞」，聚光燈就會打在牠身上，牠會跟著音樂跳一段：踩著拍子彈跳、肚子跟著晃、扭屁股、揮揮手、轉一圈，最後「登登！」擺好姿勢。柴犬的尾巴會像螺旋槳一樣轉、貓咪在空中踩踩、九尾狐把尾巴像孔雀一樣張開、小雞小鴨左右搖擺、貓頭鷹跟著拍子點頭歪頭
- 選單多了「放聚光燈」：放在桌面上一陣子，走進光圈的都會跳舞，可以好幾隻一起跳；開著非理性模式時，旁邊的也會跑過來湊熱鬧
- 小鴨的池塘變大變深了：沒有池岸，邊緣慢慢淡進桌面裡；其他寵物也會下水一起泡，泡在一起還會打水仗：用爪子撥水、拍翅膀、甩尾巴，水花飛過去潑到對方，被潑到的會甩甩身子、笑出來，或馬上潑回去
- 戳肚子的聲音變成軟軟「噗」的一聲
- 貓曬的太陽更像真的陽光了：柔和的光束、地上一圈暖暖的亮光、會閃的浮塵，躺在裡面的貓也會被照得暖暖亮亮的
- 從不完全靜止：耳朵會抖、會眨眼、呼吸看得出來，睡覺時不管哪種睡姿，肚子都會一起一伏；笑著看你的時候會扭屁股、原地跳、轉圈、踩踩；開心或玩得正起勁時，尾巴、耳朵、翅膀一刻都不停
- 柴犬跑完、開心或玩的時候會吐舌頭喘氣；吃完零食會舔舔鼻子；啃骨頭會真的歪著頭啃、往後扯
- 開心會冒愛心，接到球會閃閃發亮，重重落地會揚起灰塵
- 叫聲換成真的動物錄音：柴犬汪汪、貓咪喵喵和呼嚕、貓頭鷹咕咕、小雞小鴨啾啾，睡覺會打呼；開心、大笑、不爽也各有自己的聲音；幾個聲音可以同時出現
- 有自己的圖示了：一窩擠在一起的肉肉；Linux 執行一次 `./chonkgene --menu-entry` 就會出現在應用程式選單裡
- 修好開心的時候畫面會卡住好幾秒、點了好像沒反應的問題；動作整體更順，摸牠、搔牠、打鬧時的反應也更即時；貓頭鷹飛上樹枝、跳躍、被拋出去時畫面不再跟不上
- 修好有幾隻在走路時，其他寵物突然變得卡卡、像慢動作的問題：現在每一隻都分得到夠用的畫面
- 修好池塘、陽光、種子等東西出現時蓋在寵物身上的問題；走進池塘時池塘不再閃爍，腳也不會從水面下露出來；池塘和陽光不會再冒在別的寵物腳下；定身術的泡泡會照著寵物的大小變大，頭和耳朵不再露在外面；招喚術叫了大家卻沒人過來的問題也修好了；小雞小鴨被搔癢轉頭不再變形，搔完回頭也變得輕柔；動作結束時不再「啪」一下彈回去，甩尾巴、拍翅膀這類快動作也更順；捲著睡的貓尾巴不再擠成一團；兩隻離太遠時不會再隔空吵架
- 每隻都有自己喜歡和不喜歡被摸的地方：貓咪最愛被摸下巴和肚子，柴犬最愛被抓尾巴根（後腳會跟著踢），小雞小鴨最愛被摸背，貓頭鷹愛被摸臉，九尾狐愛被摸尾巴。摸到最愛的地方會瞇眼、冒愛心、呼嚕呼嚕；摸到不喜歡的地方（腳、翅膀、大部分的尾巴）會皺眉、耳朵往後，按住不放就跳開
- 曼赤肯的肚子很好摸，但摸太久小心：牠會一把抱住你的手，後腳踢踢踢
- 可以抱抱了：右鍵選「抱抱」或在寵物身上點兩下，你的手會把牠圈住，牠會靠進你懷裡蹭蹭、冒愛心
- 寵物之間也會互相抱：開著非理性模式時，牠們偶爾會走過去面對面抱抱、臉貼臉一起搖；吵完架和好後也會抱一下；也可以在「叫牠…」選「去抱抱…」指定要抱誰。九尾狐則會站起來熊抱，小雞小鴨會被抱到腳離地
- 九尾狐有了新個性：對其他寵物是霸道的大姊姊，對你嘴硬心軟
- 預設同時在桌面上的寵物變成 7 隻（每一種一隻）；之前沒改過這個設定的會自動跟著變
- 設定裡「我的寵物」的預覽動起來更順，不再一頓一頓、慢半拍
- 修好從池塘出來的一瞬間，腳下出現一塊方方的殘影：池塘時間到了會慢慢乾掉，泡在裡面的寵物身上的水也跟著退；走出水的時候水面會順順地降下來
- 資料夾裡會留一份 `chonkgene.log`；遇到怪怪的狀況時，把它附在回報裡會很有幫助

**之前的版本**
- 六隻改成圓滾滾、毛茸茸的 3D 玩偶，走路會晃、轉身會擠扁再翻過來
- 修好開著一陣子後會一直佔用一顆 CPU、動一動會留下殘影的問題

**其他功能**
- 柴犬、曼赤肯貓、蘇格蘭折耳貓、貓頭鷹、小雞、小鴨、九尾狐，各有預設的名字、個性和毛色
- 戳肚子會晃；連戳會翻肚爆笑或一臉厭世；拎起來、搖、丟出去
- 會睡覺（鼻涕泡、說夢話）；輕輕叫醒沒事，搖醒會有起床氣
- 親密度只升不降，每天可以餵 3 份零食
- 非理性模式：兩隻以上會吵架或一起玩；吵架有來有往：互瞪、你一句我一句、追著跑、背對背生悶氣，再由一隻過去道歉，被拒絕一次後才和好；小雞和小鴨會雞同鴨講
- 聲音模式、全螢幕時自動躲起來、Ctrl+Alt+P 一鍵收起來、托盤圖示、開機時一起醒來
- 設定視窗：領養、改名字和「牠怎麼叫你」、毛色、體型、大小、個性

**已知的限制**
- 沒有獨立顯示卡也能用；但沒有可用的 GPU 時會改用預先畫好的圖片，動作會少很多
- 叫聲還是合成的暫定版，之後會換
- Windows 可能出現 SmartScreen 警告（尚未簽章）：按「其他資訊 › 仍要執行」
- Linux 的 Wayland 工作階段裡，寵物看不到一般 Wayland 視窗，有些功能會打折扣

問題和想法歡迎回報到 Issues。
