肉肉賴桌的第一個測試版：六隻胖嘟嘟的桌面寵物，解壓縮就能用。

**下載**：Windows 選 `windows-x64.zip`；Linux 選 `linux-x86_64.tar.gz`（一般電腦）或 `linux-aarch64.tar.gz`（ARM）。解壓縮後執行 `chonkGene.exe` 或 `chonkgene`。可以用 `SHA256SUMS` 核對檔案。

**這一版有**
- 柴犬、曼赤肯貓、蘇格蘭折耳貓、貓頭鷹、小雞、小鴨，各有預設的名字、個性和毛色
- 戳肚子會晃；連戳會翻肚爆笑或一臉厭世；拎起來、搖、丟出去
- 會睡覺（鼻涕泡、說夢話）；輕輕叫醒沒事，搖醒會有起床氣
- 親密度只升不降，每天可以餵 3 份零食
- 非理性模式：兩隻以上會吵架，最後一定和好；小雞和小鴨會雞同鴨講
- 聲音模式、全螢幕時自動躲起來、Ctrl+Alt+P 一鍵收起來、托盤圖示、開機時一起醒來
- 設定視窗：領養、改名字和「牠怎麼叫你」、毛色、體型、大小、個性

**已知的限制**
- 美術和聲音都是暫定版；翻肚、裝死等正式姿勢還沒有
- Windows 可能出現 SmartScreen 警告（尚未簽章）：按「其他資訊 › 仍要執行」
- Linux 的 Wayland 工作階段裡，寵物看不到一般 Wayland 視窗，有些功能會打折扣
